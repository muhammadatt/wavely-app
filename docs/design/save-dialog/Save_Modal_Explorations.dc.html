1Save modal — four directions

What I'd fix in the current dialog: the overwrite warning sits under the bit-depth controls, far from the file name that causes it; the output spec is spread over three rows with no sense of what changed from the original; and 32-bit float stays on offer when MP3 is picked. Each direction below tackles those differently — mix and match.

1aRefined classic

Same structure, sharper. The name conflict is resolved right under the name field (Replace / Keep both). Formats become small cards that carry their size. Values matching the original get a quiet dot.
